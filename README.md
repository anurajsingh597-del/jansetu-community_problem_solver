# 🇮🇳 JanSetu – Community Problem Solving Platform

> **The Setu Between Citizens & Solutions**

JanSetu is a civic innovation platform designed to connect **citizens, colleges, student teams, researchers, startups and industry partners** to identify real-world community problems and work together towards practical solutions.

The platform provides a centralized space where citizens can submit problems, communities can support them, colleges can build solution teams, and industry partners can mentor, sponsor and help scale impactful solutions.


## 🎯 Vision

Many real-world community problems remain unresolved because there is no simple bridge between:

- 👥 Citizens who experience problems
- 🎓 Colleges and student innovators
- 🧑‍🏫 Faculty and researchers
- 🏢 Industries and startups
- 🤝 Organizations working for community development

**JanSetu acts as this bridge — connecting problems with people who can solve them.**

---

## ✨ Key Features

### 👥 Citizen Problem Reporting

Citizens can submit community problems with:

- Problem title
- Category
- Location
- District
- Urgency level
- Number of people affected
- Detailed description
- Community impact
- Suggested solution
- Photos, videos and PDF evidence

Each submission receives a unique tracking ID.

---

### 🗺️ Interactive Problem Map

JanSetu provides an interactive map to visualize community challenges geographically.

Users can filter problems by:

- 🚨 Disaster
- 💧 Water
- 🎓 Education
- 🏥 Healthcare
- 🌾 Agriculture

Map markers display important information such as location, affected population, priority score and current status.

The map is implemented using **Leaflet.js and OpenStreetMap**.


### 📊 Transparent Priority Score

Problems are assigned a priority score based on factors such as:

- Urgency
- Number of people affected
- Severity
- Community support

The goal is to help solution teams and partners identify high-impact problems instead of relying only on subjective decisions.
